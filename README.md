# Hi, I'm Benjamin Van Laethem

I run an organic grocery in Brussels. I moved the shop onto a self-hosted
**Odoo 16** (POS, purchasing, stock, invoicing) and keep extending it with
custom modules: **34 are in production today**, used daily at the till and
in the back office.

**How I work, openly:** a need on the shop floor → a written specification →
code written with an AI assistant → tests on a copy of the database →
production. I own the problem, the spec, the review and the result.

**Selected modules**
- [odoo-product-auto-pricing](https://github.com/benvala-png/odoo-product-auto-pricing) — sale price from the cheapest supplier + category margin, with a review screen instead of silent changes
- [pos_manual_weight_custom](https://github.com/benvala-png/pos_manual_weight_custom) — read the scale over HTTP at the till, manual entry as fallback
- [pos_barcode_camera_scan](https://github.com/benvala-png/pos_barcode_camera_scan) — scan barcodes with a phone or tablet camera in the POS
- [product_template_list_extra](https://github.com/benvala-png/product_template_list_extra) — optional columns to check and compare products without opening each form
